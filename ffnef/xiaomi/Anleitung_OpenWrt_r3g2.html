OpenWrt Installation: Xiaomi Mi Router 3G v2

Target: ramips / mt7621
SoC: MediaTek MT7621AN
Flash Partition: OS1
Achtung: Flashen auf eigene Gefahr. Gerät während des Vorgangs nicht ausschalten!

1. Vorbereitung (OpenWRTInvasion)

git clone https://github.com/acecilia/OpenWRTInvasion.git
cd OpenWRTInvasion
pip3 install -r requirements.txt

2. Stok auslesen & Exploit

Melden Sie sich unter http://192.168.31.1 an und kopieren Sie den stok-Wert aus der URL.

python3 remote_command_execution_vulnerability.py

3. Firmware herunterladen & HTTP-Server

Firmware herunterladen: OpenWrt Download

python3 -m http.server 8000

4. Flashen via Telnet

telnet 192.168.31.1
cd /tmp
wget http://<PC-IP>:8000/openwrt-ramips-mt7621-xiaomi_mi-router-3g-v2-squashfs-sysupgrade.bin -O firmware.bin
mtd -r write firmware.bin OS1

5. Erstzugriff

Nach dem Neustrat erreichbar unter http://192.168.1.1
